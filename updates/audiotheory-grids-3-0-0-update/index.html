AudioTheory GridsVersion 3.0.0

A big update is here for AudioTheory Grids. This update brings some significant improvements to the Grid itself, with the goal being to make it function more like the piano roll/ MIDI editor that you'd find in a fully fledged DAW.

Enhancements are as follows:

  • Click and drag to re-arrange notes directly on the grid
  • Dedicated selector, marquee and eraser tools. Choose from the left-hand toolbar.
  • Resize notes directly from the grid by dragging the left or right edge
  • Note lengths are no longer locked to the grid itself
  • Right-click on a note to split, quantise, delete, or change the note velocity
  • Multiple notes can now sit on top of each other on the grid
  • Individual octave modifier for each instrument/grid
  • The grid now responds with visual feedback to better indicate exactly what's playing

ASIO support has also been enhanced and now it's possible to use any external interface that supports it for lightning fast response times. The audio driver dropdown in the settings now lists all options available for the computer, and ASIO4All remains as an easy method of achieving low-latency playback without the need for external hardware.

Some further improvements made previously to AudioTheory Guitars and AudioTheory Piano Keys now also make their way to AudioTheory Grids:

Added

  • Scale Inspector popup
  • Extended scale library (Jazz Scales, Exotic Scales and Japanese Scales)
  • New options to play scales ascending, descending, or both
  • Various small design and colour changes have been made across the different themes
  • German note names have been added as an option within the application settings

Changed

  • Scale playback runs over one octave, rather than continuing for the full length of the keyboard
  • Diminished scales have been moved into the exotic tab in the scale library

Fixed

  • A few small scale corrections and label adjustments
