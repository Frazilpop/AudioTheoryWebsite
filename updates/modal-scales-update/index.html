AudioTheory GuitarsModal Scales Update

AudioTheory Guitars version 1.10.0 focuses primarily on scales, adding modal scales to the available set of reference diagrams and presets.

These are accessed using a new 4th 'modes' tab on the fullscreen scale selector ('scale ––> all scales' in the bottom left). From here you can select the desired mode (Ionian, Dorian, Phrygian etc.) to view the relevant scales.

This update also includes a couple more changes:

There is also a new 'scale looping' button on the right hand side of the screen. This can be toggled to loop scale playback.

All existing scale diagrams now display over a single octave. This makes it easier to differentiate between a mode and its relative key.

All updates are free for owners of AudioTheory Guitars. The app is available now on Steam and the Mac App Store.
