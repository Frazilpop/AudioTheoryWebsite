Update Log

3.6.0 – 28th August 2026

Added
  • Audio interface support for ASIO output
  • Swap audio drivers at runtime without the need for an application restart
Changed
  • Refactored save/load system. This is mostly internal but does have some user benefits. Partial preset files can now be loaded, whereas previously the system was quite strict in requiring a line match for the original preset save file.
  • Keyboard overlay type has been simplified into a dropdown in the application settings
Fixed
  • Faster application load times specifically when using ASIO

3.5.0 – 4th February 2026

Added
  • Contextual note selector that shows either a sharp or flat note based on the current config.
  • Scale Inspector popup
  • Extended scale library (Jazz Scales, Exotic Scales and Japanese Scales)
  • New options to play scales ascending, descending, or both
  • German note names have been added as an option within the application settings
Changed
  • The position of the play button has been adjusted for scales
  • Auto-loading chords with scales has been streamlined. Pentatonic scales now load the standard set of major chords. Melodic scales no longer auto-load chords, and a message now displays at the top of screen when a set of chords are loaded on scale change.
  • Scale playback runs over one octave, rather than continuing for the full length of the keyboard
  • Diminished scales have been moved into the exotic tab in the scale library
  • Spacing has been revised for chord names in alt note name languages
  • (no capo) text now no longer shows in the chord library if a capo is applied (only shows in the main view)
Fixed
  • A few small scale corrections and label adjustments

3.4.1 – 8th October 2025

Fixed
  • Unity upgrade to fix security issue CVE-2025-59489

3.4.0 – 18th September 2025

Added
  • Option to set manual sharp and flat defaults in the application settings
  • Scale highlighting support for theoretical scales
  • Default display settings have been optimised for Steam Deck
Changed
  • The note selector now references the sharp/ flat state of accidentals when indicating a scale match
Fixed
  • Fixed an issue with the scale type label not displaying correctly on certain scale sets

3.3.1 – 1st April 2025
